Server-side loading

Same grid, but the rows live behind an HTTP API. Search, sort, pagination and export scope are handled by the server on every request.

remote mode Local demo

Start the API with python server_side.py, then open http://localhost:8001/server_side.html. A static server on port 8000 works too: http://localhost:8000/server_side.html (the page defaults to http://localhost:8001/api/users). Override with ?api=….
